# 以小程序当前功能为基准的移植范围

本轮基于留白当前小程序的功能与设计整理网页及浏览器扩展。两个公开端共用界面和数据模块；微信账号与小程序云能力需要对应的平台适配，不把它们冒充成浏览器能力。

| 功能 | 网页 | 浏览器扩展 |
| --- | --- | --- |
| 心情与文字、编辑、草稿、标签、搜索、日历 | 本机 | 完整页与网页共用，弹窗可快速记 |
| 文字、照片、贴纸、笔迹手帐与模板、本子 | 支持 | 完整页支持 |
| 语音记录、播放与原音频下载 | 浏览器授权麦克风 | 完整页，需浏览器支持 |

## 平台差异

- **账号**：公开版使用自托管服务维护者创建的账号，不接入微信登录，也无法直接读取微信头像昵称。头像由用户主动选图，昵称自行填写。
- **云资源**：不包含作者的 AppID、云环境、赠送 token、密钥或维护者账号。AI 与同步不借用作者生产服务。
- **图片分享**：公开版提供品牌署名和 GitHub 地址，不嵌入尚未发布的小程序码，也不调用微信“转发给好友”接口。文件下载后由使用者选择分享方式。
- **导出与同步**：网页与扩展的本项目完整备份可互通；小程序原生备份含微信本机文件路径，当前没有实现直接导入。联网同步是显式快照管理，不是多端实时协同；同 ID 内容不同会停止合并。
- **引文库**：公开仓库附带已有原创一笺、古典诗词与公版文学自译短摘，并标注出处。没有把全部歌词、影视或剧集内容声明为可自由再分发的素材；新增引文时需自行确认使用条件。
- **关怀**：独立本机空间保留，不连接 AI 和云端服务。浏览器清理、卸载或操作系统回收存储仍可能删除数据，不称为加密保险箱。
- **语音**：依赖浏览器 MediaRecorder 和音频格式支持。系统中断、锁屏或进程被终止时不保证连续录音；手机真机麦克风未在本轮验证。
- **练习进程**：网页和扩展包含三步本机书写引导、进度保存及回看；它不要求连续打卡，不作评估或治疗。已有呼吸、声音和活动工具保留。

桌面浏览器的模拟窄屏结果不等于 iPhone 微信或 Safari 真机验收；小程序当前审核状态以微信后台为准。
