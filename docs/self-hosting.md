# 可选自托管服务

静态网页和扩展可以独立记录。此服务用于你明确选择的 AI、普通空间备份同步，以及来信与回复；不会连接作者的小程序云环境。

## 本机服务与账号

需要 Node.js 22 或更高版本，运行时无第三方依赖：

```bash
npm run build:all
npm start
```

默认只监听 127.0.0.1:4187。数据目录为项目中的 `.liubai-data/`，已被忽略，不应提交到 Git。也可以用 `LIUBAI_DATA_DIR` 指向仓库以外的私有目录。

账号由维护者创建，不开放注册。下面为 macOS / Linux 的交互方式，口令输入时不显示，输入后不会写入命令历史：

```bash
read -s LIUBAI_USER_PASSWORD
export LIUBAI_USER_PASSWORD
npm run service -- user myname
unset LIUBAI_USER_PASSWORD
```

口令需为 12–256 个字符；账号为 3–60 个字母、数字、下划线或连字符。服务保存 scrypt 派生值，不保存明文口令。账号创建命令不会覆盖已有账号。Windows PowerShell 可以在本机设置相同环境变量后运行管理命令；不要将口令写入公开脚本。

在“我的 → 登录与跨设备同步”填写服务地址，点击连接，再使用维护者创建的账号登录。登录只发送账号与口令，不附带记录。会话在服务内存及浏览器 sessionStorage 中保存，最长8小时；服务重启后需要重新登录。

## 多设备与公开部署

同一账号可以从不同设备登录。同步以显式上传、下载与合并进行，不会自动扫描或持续上传日记。服务器维护一个带修订号的普通空间快照，过期修订的上传会被拒绝。覆盖云端副本前，请根据需要先下载旧版。

公网部署必须提供 HTTPS，并配置：

| 变量 | 用途 |
| --- | --- |
| `HOST` | 默认127.0.0.1；反向代理或容器部署按实际环境设置 |
| `PORT` | 默认4187 |
| `LIUBAI_PUBLIC_ORIGIN` | 本服务的完整来源，例如 `https://journal.example.org`，不带路径 |
| `LIUBAI_DATA_DIR` | 私有数据目录，建议放在仓库外并定期备份 |
| `LIUBAI_ALLOWED_ORIGINS` | 允许连接的额外网页或扩展来源，逗号分隔，逐个列出 |

如果使用 GitHub Pages 前端连接自己的服务器，允许来源为 `https://workstonedai-collab.github.io`。如果使用扩展，来源形如 `chrome-extension://你的扩展ID`，请从自己的浏览器扩展管理页核对；不同安装可能有不同 ID。服务不使用通配来源。

账号、记录和附件以文件保存在服务端，未做静态加密；HTTPS 只保护传输。适用于个人或受控小组自托管，不是开放注册的多租户云产品。运行维护、账号恢复、服务器备份、审计与存储费用由部署者负责。

## 接入腾讯混元

AI 默认关闭，需要同时设置 `HUNYUAN_API_KEY` 与 `HUNYUAN_MODEL`。`HUNYUAN_CHAT_ENDPOINT` 默认采用腾讯公布的混元兼容接口；如果使用腾讯其他接入渠道，需要部署者按自己的服务文档配置相应地址和模型名。

配置应保留在服务器环境中，不要填进网页源码、扩展文件或 Git 仓库。项目不会自动读取 `.env`，请通过部署平台或本机环境设置。密钥不会返回给浏览器。

- 每次请求需要用户确认；服务检查 `confirmed`、文字长度和角色范围。
- 每账号每天最多10次请求，单次输出受 token 上限限制；服务重启会清空内存计数。它是基本请求控制，**不是账户账单的硬上限**。
- 对话发送最近至多10条上下文及已启用的偏好、确认记忆；回望发送选择范围内的文字记录。照片、录音和手帐图片不送给模型。
- AI 不进行诊断、评分或隐性风险判定；将缺失记录保留为缺失，不把相关写成因果。即时危险的表达优先引导现实安全支持。

腾讯的小程序成长计划、CloudBase 模型调用与混元 API Key 是不同接入条件。是否能使用同一份赠送额度，需要在自己的控制台确认；本项目没有验证或承诺可跨渠道复用，也不会自动开通付费服务。

参考：[腾讯混元官方兼容接口说明](https://cloud.tencent.com/document/product/1729/111007)。该文档同时提示平台能力向 TokenHub 迁移，实际模型与额度以你的账号为准。

## 来信与回复

用户登录后可在“意见与回复”发送文字来信；不会自动附带日记、日志或照片。维护者在自己的服务器终端查看：

```bash
npm run service -- inbox myname
```

回复时，将回复文字放在本机环境变量 `LIUBAI_REPLY_TEXT` 中，再运行：

```bash
npm run service -- reply myname THREAD_ID
```

之后清除该环境变量。`THREAD_ID` 来自上一条查看命令。来信及回复保存在该账号的来信文件里，用户重新打开来信箱即可查看。没有后台自动通知、邮件发送或手机推送。

## 删除与退出

“删除云端副本”只删除该账号的同步快照，不会删除本机记录或来信。退出登录撤销当前服务会话，并清除浏览器中的会话令牌；不删除已保存的服务器文件。需要删除账号及所有数据时，由维护者在停止服务后按账号目录执行管理，并处理备份副本。
