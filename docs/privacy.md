# 数据与隐私

默认没有账号、统计埋点、广告 SDK、第三方追踪或自动上传日记。字体与插画随静态包提供，不需要从外部字体服务加载。

| 内容 | 默认位置 | 什么时候发送 |
| --- | --- | --- |
| 文字、便签、设置、主题与周笺 | 当前浏览器本机存储 | 主动导出，或登录自托管服务后上传普通空间备份 |
| 照片、录音、手帐附件与媒体草稿 | IndexedDB | 保存附件后的备份/同步；不发给 AI |
| 头像昵称 | 当前空间本机存储 | 选择放进分享图时出现在图片上 |
| AI 对话、回应偏好与确认记忆 | 本机独立文档；对话保留可关闭 | 发送预览确认后，选中的文字与启用的背景发送给部署者配置的混元服务 |
| 关怀空间 | 独立本机名称空间 | 不连接云端；用户自行导出备份或文件 |
| 来信与回复 | 已连接服务的账号目录 | 用户点击发送来信或回复；不自动附加其他内容 |
| 登录凭据 | 口令派生值在服务端，临时令牌在会话存储 | 用户明确选择服务并提交登录 |

本机存储、导出文件和服务器保存的快照均未做静态加密。浏览器可能清理本机数据；卸载扩展会丢失其存储。分享图片上的文字和照片会随图片公开给接收者；请检查预览。

同步采用手动备份快照。上传会更新服务器上的该账号副本，下载合并不会主动删除本机记录。同 ID 日记或媒体内容不同会拒绝合并。附件与文字使用多个浏览器数据库，不能保证跨数据库原子事务；存储故障时可能只导入部分内容，保留原文件后重试或检查。重复的相同内容会跳过，旧备份不会因此被改写。

退出登录不等于删除云端数据；“删除云端副本”只删除同步快照。账号、来信及服务器备份的整体删除，由你选择的服务维护者管理。

扩展没有内容脚本，不读取其他网页内容、历史、书签或 Cookies。默认本机功能无网站权限；连接你填写的服务地址时会申请对应可选权限。扩展和静态网页没有放入模型密钥。

AI 只辅助自我梳理。五种心情是记录分类，不是心理诊断量表；漏记不会算作平稳，标签共现不代表因果。AI 可能误解、遗漏或出错，不能替代现实支持与专业诊疗。
