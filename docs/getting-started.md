# 开始使用

## 网页

直接打开 [GitHub Pages 网页版](https://workstonedai-collab.github.io/liubai/)。先选一个心情，再写下想留下的话。新用户默认使用轻记；页面上方和“我的”中都能切换模式。

网页版和插件版都有四种底色、独立关怀空间、日历、日记、手帐、照片、语音、便签，以及按需打开的回看与关怀工具。功能入口随模式变化，已有内容不会因隐藏入口而删除。

本机运行需要 Node.js 22：

```bash
git clone https://github.com/workstonedai-collab/liubai.git
cd liubai
npm run dev
```

访问 http://127.0.0.1:4187 。没有 npm 安装步骤；启动不会调用模型。停止时在终端按 Ctrl+C。

## 浏览器扩展

1. 从 [Release](https://github.com/workstonedai-collab/liubai/releases/latest) 下载 `liubai-extension` 压缩包并解压；或者运行 `npm run build:extension`。
2. 在 Chrome 地址栏输入 `chrome://extensions`，或在 Edge 输入 `edge://extensions`。
3. 开启“开发者模式”，点击“加载已解压的扩展程序”。
4. 选择解压后的目录；自行构建时选择 `dist/extension`。
5. 将留白固定在工具栏。点图标快速记录，点“打开完整日记”进入所有功能。

这是自行加载的开源扩展，尚未提交浏览器商店；浏览器可能显示开发者模式提示。Safari 和 Firefox 未完成扩展适配，不列为已支持平台。

扩展不会读取其他网页，没有内容脚本，也不请求标签页内容、历史或书签权限。配置自托管服务时，浏览器会单独询问是否允许连接你填写的地址。

更新扩展前请先备份。加载另一目录可能生成不同的扩展 ID，对应不同的存储空间；不要假定旧数据会自动出现。相同扩展 ID 的早期私有版本会尝试复制可读取的旧文字记录，不删除旧副本；失败时可以使用原文字 JSON 备份导入。

## 几个常用入口

- **我的**：左上角的小圆标，放头像昵称、模式、外观、偏好、备份、服务连接与来信。
- **手帐**：按钮始终显示“手帐”。有未完成草稿时，先选接续，或收好原页另开一页。展开“添加文字与照片”加入本机图片；插画与信纸也可从纸页工具中选择。
- **情绪线索**：按日历找记录；沉浸或自选模式可建立主题、周笺和小册子。轻记只保留日历。
- **分享**：文字日记和一笺先生成预览，再下载分享图；手帐可导出长图。公开版不附上尚未发布的小程序码。
- **备份与恢复**：当前网页、扩展和微信小程序各有自己的存储。网页和扩展可以互相导入本项目完整备份；小程序的原生附件格式尚未实现直接恢复。

## 先备份，再换设备

在“我的 → 备份与恢复”下载当前空间的完整备份。确认文件确实保存，再进行清理、卸载或迁移。未完成手帐和录音请先保存，或使用各自的草稿下载入口。

AI、同步和来信需要另行连接服务，见[自托管说明](self-hosting.md)。本机记录不需要这些配置。
